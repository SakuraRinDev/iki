# IKI

スマホの画面いっぱいに並んだ光るパッドで遊ぶ楽器。

- どのパッドもドレミ（ハ長調）の音。押したところが鳴り、何本でも同時に押せる（最大6音）
- 下の段ほど低く、上の段ほど高い。1段上がるごとに3度上がるので、縦に3つ並べて押すと和音になる
- 指を滑らせると隣のパッドへなめらかにつながる
- 上端を持ち上げると強く明るい音に。時計回りにひねると半音上（♯）、反時計回りで半音下（♭）
- 音はすべてWeb Audioで合成したサックス風の音色、見た目はWebGL。外部ファイルなしの1枚のHTML

傾きセンサーはHTTPSのページとして直接開いたときに使えます。iPhoneでは最初のタップのあとに許可を求められます。

前のサックス型（真鍮と真珠のキー）は `sax.html` に残しています。
